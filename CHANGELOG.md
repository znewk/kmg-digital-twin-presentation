# Журнал версий

Крупные блоки работ с точками отката. Каждая версия помечена тегом в git —
вернуться к любой можно одной командой.

## Как это устроено

**Коммит = одно осмысленное изменение.** Не «правки за день» и не «фиксы», а
конкретное: что изменилось и почему. В сообщении коммита всегда есть причина —
через полгода она важнее, чем перечень тронутых файлов.

**Тег = состояние, к которому имеет смысл вернуться.** Ставится на завершённом
блоке работ, а не на каждом коммите: точка отката ценна тогда, когда она
означает «здесь всё работало и выглядело так-то».

```bash
git tag -n9                      # список версий с описанием
git checkout v0.2.0              # посмотреть состояние версии
git diff v0.2.0 v0.3.0 --stat    # что изменилось между версиями
git revert <хеш>                 # отменить одно изменение, сохранив историю
```

Откат ветки к версии — `git reset --hard v0.2.0` — переписывает историю и
годится только до пуша. После пуша безопаснее `git revert`.

## v0.2.0 — 12.08.2026 · `70911cf`

Полный цикл добычи, разборы модулей по контурам, переход на терминологию ABAI.
Состояние, показанное заказчику.

### Полный цикл добычи (§4.4)

Переделан дважды. Первая версия подсвечивала все сети разом и провалилась: было
видно, что «всё связано», и непонятно ни одно звено. Вторая — раскадровка из 16
кадров на одной скважине, где камера подходит вплотную к тому, о чём речь.

- маршрут **не назначен, а найден**: по 649 трассам нефтесбора строится граф, и
  путь от замерной установки до сборного пункта ищется поиском кратчайшего.
  Результат — VMB_2036 (М-II) → ГЗУ-6 → 1,57 км коллектора → Мини СП N43,
  выведен в панель и проверяется по чертежу;
- кадр задаёт только смысл — на что смотрим, какой крупности, что движется, что
  сказать; координат в раскадровке нет, при смене маршрута кадры встают сами;
- каждый кадр включает свои режимы сцены и гасит чужие;
- текст написан для аудитории, которая нефтедобычу не знает.

Коммиты: `e73009a`, `cb3f3e2`, `66dcd44`, `9bfaa9e`, `2e143e2`, `6aea806`,
`55edc3d`, `370b9a7`, `7b7cbf3`, `5854e9a`, `70911cf`.

ними закрытой. Стали пятью разделами по клику с экрана архитектуры. Линейный

- досье модулей собрано из первоисточников — отчёта об обследовании, сценария

### Витрина

Схематичный цилиндр с одной скважиной заменён диорамой промысла на настоящих
моделях: работающие качалки, ГЗУ, сборный пункт, КНС, ВЛ. Слои выгнуты сводом,
залежь — линза над водонефтяным контактом.

Коммиты: `541a312`, `70e33e4`.

### Интерфейс

- масштабируется под размер экрана: показ идёт не на том мониторе, на котором
  собирали;
- панели не налезают друг на друга ни в одном из трёх режимов;
- режим ровно один: линейный показ, полный цикл или разбор модуля.

Коммиты: `4303972`, `b5e861e`, `d12eacf`.
